# MWI Battle FX · 公主连接风格

银河奶牛放置（Milky Way Idle）的战斗动画油猴脚本，基于 [wow121/mwi-battle-fx](https://github.com/wow121/mwi-battle-fx) 改造。

## 安装

1. 在浏览器中安装 Tampermonkey 等用户脚本管理器。
2. 打开仓库里的 `mwi-battle-fx-priconne.user.js`，点击 **Raw**，按提示安装。
3. 禁用原版 MWI Battle FX 脚本，避免重复运行，再刷新游戏页面。

## 功能

- 底部玩家头像卡，头像上方显示 Buff，下方显示 HP 和 MP。
- 怪物头顶血条；Boss 使用居中的顶部血条，显示名称、等级和血量。
- 致命一击的红色受损段收缩到零后再隐藏血条。
- Boss 血条右侧显示沙漏计时器；左上角 TOTAL DAMAGE 仅在 Boss 战显示，每场清零。
- 角色原地攻击，技能名称以施法者头顶的白色气泡显示。
- 清场后停留 1 秒，再向右退场、黑屏转场、从左侧入场；整段约 3 秒。
- 怪物直接出现在站位上，无入场动画；新一波战斗数据即时同步。

## 说明

脚本只读取游戏消息，不修改游戏数据。图像素材仍依赖原项目的素材 CDN。

等级缺失时显示 `—`。中途加入战斗时，用时和伤害仅统计插件观察到的部分；伤害按怪物有效扣血累计，排除过量伤害。

已进行浏览器模拟测试，包括布局、血量更新、Boss 识别、清场转场及消息同步；真实游戏中的兼容性仍需验证。

当前版本：`0.11.0-priconne.14`。当前脚本关闭自动更新，后续版本请手动安装。
